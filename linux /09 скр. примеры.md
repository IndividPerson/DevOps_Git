Этот скрипт **проверяет доступность трех IP-адресов в сети с помощью команды `ping`**
![[Pasted image 20260714014240.png]]
**`ping -c 1 -w 1 8.8.8.$i`**:

- `ping` — отправляет сетевой пакет для проверки связи.
    
- `-c 1` — отправить ровно **один** пакет (чтобы не пинговать бесконечно).
    
- `-w 1` — ждать ответа не дольше **одной** секунды.
    
- `8.8.8.$i` — подставляет значение `$i`. Скрипт будет проверять адреса `8.8.8.7`, `8.8.8.8` и `8.8.8.9`.
- **`>/dev/null`**: Этот кусочек скрывает технический вывод команды `ping` (чтобы вы не видели в терминале лишние цифры о времени отклика, а только результат, который мы сами написали в `echo`). (своего рода мусорник)
