
### Фундаментальні концепції
- **UID (User ID) та GID (Group ID):** Linux ідентифікує користувачів та групи за числовими ID, а не лише за іменами. Це критично для розуміння доступу до файлів у контейнерах.
### Ключові системні файли

- **`/etc/passwd`:** Зберігає інформацію про користувачів (ім'я, UID, GID, домашня директорія, оболонка).
    
- **`/etc/group`:** Містить список усіх груп у системі та інформацію про те, які користувачі до них належать.

`getent passwd <ім'я_користувача>`- **`getent`** (_get entries_) — це команда, яка звертається до системних баз даних для отримання інформації про записи (користувачів, групи, хости тощо).

`useradd`, `usermod`, `userdel` — керування користувачами.
**`useradd`**: Створює нового користувача.
- _Приклад:_ `sudo useradd -m -s /bin/bash username`
- _-m_: створює домашню директорію.
- _-s_: встановлює оболонку (shell).

**ГРУПЫ**
#### 1. `groupadd` — Створення нової групи

Створює групу, до якої ти зможеш додавати користувачів.

- **Синтаксис:** `sudo groupadd назва_групи`
    
- _Навіщо:_ Наприклад, ти хочеш створити групу `developers`, щоб дати їм спільний доступ до папки з проектом.
    

#### 2. `groupmod` — Зміна назви групи

Дозволяє перейменувати групу (рідко потрібно, але корисно знати).

- **Синтаксис:** `sudo groupmod -n нова_назва стара_назва`
    

#### 3. `groupdel` — Видалення групи

Видаляє групу із системи.

- **Синтаксис:** `sudo groupdel назва_групи`
    
- _Важливо:_ Не можна видалити групу, яка є основною для якогось користувача.
    

### Як пов'язати Користувача та Групу

Це найважливіша частина, яку ти будеш робити щодня як DevOps:

- **Додавання користувача в групу:**
    
    Bash
    
    ```
    sudo usermod -aG назва_групи ім'я_користувача
    ```
    
    _(Пам'ятай: `-aG` означає "Append to Group" — додати, не видаляючи з інших)._
    
- **Перевірка груп користувача:** Щоб дізнатися, в яких групах знаходиться користувач, введи:
    
    Bash
    
    ```
    groups ім'я_користувача
    ```
