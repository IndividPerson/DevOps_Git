### 1. **Ping**

- **Назначение:** Проверяет, жив ли хост (доступность узла в сети) и задержку соединения (RTT — Round Trip Time).
    
- **Как работает:** Отправляет ICMP-пакеты (`Echo Request`) на указанный IP-адрес или домен и ожидает ответа (`Echo Reply`).
    
- **Когда использовать:** Чтобы понять, есть ли вообще связь с сервером/компьютером.
    
- **Пример команды:**
    
    Bash
    
    ```
    ping google.com
    ping 8.8.8.8
    ```
    

### 2. **Curl**

- **Назначение:** Проверяет ответ сервиса по HTTP/HTTPS (а также поддерживает FTP, SFTP и другие протоколы).
    
- **Как работает:** Отправляет HTTP-запрос (GET, POST, PUT и др.) на веб-сервер и возвращает заголовки или тело ответа.
    
- **Когда использовать:** Для проверки работы API, веб-сайтов, статусов ответов (200 OK, 404 Not Found, 500 Internal Server Error).
    
- **Пример команды:**
    
    Bash
    
    ```
    # Получить заголовки ответа (1**,2**...)
    curl -I https://example.com
    
    # Сделать POST-запрос с данными
    curl -X POST -d "param=value" https://api.example.com
    
    # узнать свой внешний айпи адресс
    curl ifconfig.me
    ```
    

### 3. **Nslookup**

- **Назначение:** Проверяет работу DNS (Domain Name System).
    
- **Как работает:** Преобразует доменное имя (например, `google.com`) в IP-адрес (например, `142.250.180.206`) и наоборот.
    
- **Когда использовать:** Когда сайт не открывается по доменному имени, но работает по IP-адресу, или для проверки DNS-записей (A, MX, CNAME, TXT).
    
- **Пример команды:**
    ```
    nslookup google.com
    nslookup -type=MX domain.com
    ```
`nslookup google.com` : 
Ты спросил у своей системы: _«На какой IP-адрес мне стучаться, если я хочу открыть google.com?»_, и она выдала тебе список актуальных IP-адресов Google в интернете. (их может быть несколько)


### 4. **Traceroute** _(в Windows: `tracert`)_

- **Назначение:** Ищет место сбоя в сети и показывает полный маршрут прохождения пакетов до конечного хоста.
    
- **Как работает:** Отправляет пакеты с постепенно увеличивающимся временем жизни (TTL — Time To Live) и фиксирует каждый промежуточный маршрутизатор (хоп).
    
- **Когда использовать:** Если сервер не отвечает, чтобы понять, на каком именно этапе (у вашего провайдера, магистрального оператора или у самого сервера) теряются пакеты.
    
- **Пример команды:**
    
    Bash
    
    ```
    # Linux / macOS
    traceroute google.com
    
    # Windows
    tracert google.com
    ```
    

💡 **Шпаргалка по последовательности диагностики:**

1. **`nslookup`** — проверяем, резолвится ли доменное имя в IP.
    
2. **`ping`** — проверяем, доходят ли пакеты до этого IP.
    
3. **`traceroute`** — если ping не идет, ищем, на каком маршрутизаторе обрывается связь.
    
4. **`curl`** — если связь есть, проверяем, корректно ли отвечает сам веб-сервис/API.
