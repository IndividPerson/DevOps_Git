- **Базовый набор отладки:**
    
    - `ip a` / `ip route` — проверка интерфейсов и таблицы маршрутизации.
        
    - `ping` / `traceroute` / `mtr` — проверка доступности и поиск просадок на хопах.
        
    - `ss` / `netstat` / `lsof -i` — прослушивание портов (`ss -tulpn`) и просмотр активных сокетов.
        
    - `curl` / `wget` — проверка работы HTTP/API endpoints из консоли.
        
    - `dig` / `nslookup` — отладка DNS-запросов.
        
    - `tcpdump` / `Wireshark` — снятие и анализ дампов трафика на интерфейсе.
        
- **Фильтрация и трансляция (NAT / Firewall):**
    
    - **iptables / nftables(современнее):** понимание цепочек (`INPUT`, `OUTPUT`, `FORWARD`, `PREROUTING`, `POSTROUTING`).
        
    - UFW / firewalld — высокоуровневые утилиты настройки правил.
