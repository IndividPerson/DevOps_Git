### iproute2
— это современный набор утилит командной строки для управления сетевыми интерфейсами, IP-адресами и маршрутизацией в Linux

### MAC-адрес 
— это **уникальный физический идентификатор** вашего сетевого устройства (сетевой карты), который присваивается ему заводом-изготовителем.

### Маска подсети
Маска подсети определяет, **какая часть IP-адреса относится к сети, а какая — к конкретному устройству (хосту)** в этой сети.
На вашем скриншоте указано `192.168.1.102/24`. Число **`/24`** — это сокращенная запись маски подсети (она же `255.255.255.0`).

### Хост
В компьютерных сетях **хост (host)** — это **любое устройство**, которое имеет свой IP-адрес и подключено к сети.

`ping 8.8.8.8` - пингануть к гуглу


### . Основные команды `ip`

Базовый синтаксис: `ip [объект] [команда] [аргументы]`

- **`ip link`**: Управление сетевыми интерфейсами (поднятие/опускание, настройка MTU).
    
    - `ip link show` — список интерфейсов.
        
    - `ip link set dev(у меня enp34s0) eth0 up` — включить интерфейс.
        
- **`ip addr`**: Управление IP-адресами.
    
    - `ip addr show` — показать IP-адреса.
        
    - `ip addr add 192.168.1.10/24 dev eth0` — добавить IP-адрес.



- **Включение и выключение интерфейса (поднятие/опускание):**
    
    - `sudo ip link set dev enp34s0 up` — включает (активирует) сетевой интерфейс `enp34s0`.
        
    - `sudo ip link set dev enp34s0 down` — выключает (деактивирует) интерфейс, после чего он перестает передавать трафик.


**Изменение MTU (Maximum Transmission Unit):**

- `sudo ip link set dev enp34s0 mtu 1400` — устанавливает максимальный размер пакета (MTU) для интерфейса. Это может быть полезно, например, при настройке VPN-соединений.


**Изменение имени интерфейса (требуется, чтобы интерфейс был выключен):**

- `sudo ip link set dev enp34s0 down` — сначала нужно выключить интерфейс.
    
- `sudo ip link set dev enp34s0 name eth0` — переименовывает `enp34s0` в `eth0`.
    
- `sudo ip link set dev eth0 up` — включаем интерфейс обратно.


**Изменение MAC-адреса (spoofing):**

- `sudo ip link set dev enp34s0 down` — необходимо отключить интерфейс перед сменой адреса.
    
- `sudo ip link set dev enp34s0 address XX:XX:XX:XX:XX:XX` — меняет физический адрес устройства.
    
- `sudo ip link set dev enp34s0 up` — возвращаем в работу.


**Важно:** Все изменения, внесенные через `ip link set`, сбрасываются после перезагрузки компьютера. Для их сохранения нужно прописывать настройки в конфигурационных файлах вашего дистрибутива (например, через Netplan в Ubuntu).
