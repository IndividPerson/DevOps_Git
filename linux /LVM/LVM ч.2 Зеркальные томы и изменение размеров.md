**Зеркальный том (Mirror)** — это логический том, данные которого автоматически записываются на два (или более) физических диска одновременно (дублируются).

Главная цель — **обеспечение отказоустойчивости (High Availability)**. Если один из физических дисков выйдет из строя, система продолжит работать без потери данных со второго диска.

---
### Создание зеркального тома

Чтобы создать логический том `lv_secure` размером 20 ГБ с одним зеркалом (всего будет 2 копии данных на разных дисках) в группе `vg_storage`:

Bash

```
sudo lvcreate -m 1 -n lv_secure -L 20G vg_storage /dev/sdb1 /dev/sdc1
```

- Параметр `-m 1` означает количество **дополнительных** зеркальных копий (1 копия + 1 оригинал = 2 диска).
    
- `/dev/sdb1` и `/dev/sdc1` — физические томы, на которых будут размещены эти копии (желательно размещать их на разных физических накопителях).

---

### Шаг 1. Увеличение размера LV

- Добавить к текущему размеру тома фиксированное значение (например, +10 ГБ):
    
    Bash
    
    ```
    sudo lvextend -L +10G /dev/vg_storage/lv_data
    ```
    
- Или занять **весь оставшийся свободный объем** в группе томов (VG):
    
    Bash
    
    ```
    sudo lvextend -l +100%FREE /dev/vg_storage/lv_data
    ```



### Шаг 2. Расширение файловой системы !! (под файловую систему)

Команда зависит от того, какая файловая система используется на томе:

- **Для ext4:**
    
    Bash
    
    ```
    sudo resize2fs /dev/vg_storage/lv_data
    ```
    
    _(Указывать размер не обязательно — утилита автоматически займет весь доступный объем LV)._

## Сжатие (Уменьшение) логических томов

> [!CAUTION] **Опасно для данных!** Уменьшение размеров всегда несет риск повреждения файловой системы или потери данных. Перед началом **обязательно сделайте резервную копию (бекап)**.
> 
> - **ext4** поддерживает сжатие.
>     
> - **XFS** уменьшать **нельзя** (файловая система XFS поддерживает только расширение).
>     

Алгоритм сжатия выполняется в обратном порядке: сначала уменьшается файловая система, а только потом сам логический том.

### Шаг 1. Размонтирование файловой системы

Перед уменьшением файловую систему обязательно нужно отключить:

Bash

```
sudo umount /mnt/data
```

### Шаг 2. Проверка целостности (только для ext4)

Проверка необходима, чтобы убедиться в отсутствии ошибок перед изменением структуры:

Bash

```
sudo e2fsck -f /dev/vg_storage/lv_data
```

### Шаг 3. Уменьшение файловой системы

Укажите целевой размер файловой системы (например, уменьшить до 30 ГБ):

Bash

```
sudo resize2fs /dev/vg_storage/lv_data 30G
```

### Шаг 4. Уменьшение размера LV

После успешного сжатия файловой системы уменьшайте сам логический том до **того же** размера (или чуть большего, но **ни в коем случае не меньше**, иначе вырезать часть файловой системы):

Bash

```
sudo lvreduce -L 30G /dev/vg_storage/lv_data
```

### Шаг 5. Повторное монтирование

Верните файловую систему в работу:

Bash

```
sudo mount /dev/vg_storage/lv_data /mnt/data
```
