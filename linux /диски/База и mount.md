В Linux всё есть файл. Диски находятся в директории `/dev/`.

- **Именование:**
    
    - `/dev/sda`, `/dev/sdb` — традиционные SCSI/SATA/SSD диски.
        
    - `/dev/nvme0n1` — NVMe накопители.
        
- **Разделы:** `/dev/sda1` (первый раздел на первом диске), `/dev/nvme0n1p1` (первый раздел на NVMe).
------------------------------------------------------------

!!!Команда `mount` в Linux— это «мост» между физическим оборудованием (или сетевым ресурсом или диском) и твоей файловой системой. В Linux **всё** должно быть примонтировано к какому-то пути (каталогу)


Сначала узнайте, под каким именем система видит вашу флешку. Откройте терминал и введите: чтобы узнать то что нужно ниже
```
lsblk
```

дальше: (что бы смонтировать)
```
sudo mount [путь к устройство] [путь к точке_монтирования]
```

что бы отмонтировать:
```
sudo umount [путь к точке_монтирования]
```

## sudo blkid !!
— просмотр UUID и типа файловой системы
#### Роль в настройке `/etc/fstab`

Файл `/etc/fstab` отвечает за автоматическое монтирование разделов при загрузке системы. Использование имен типа `/dev/sda1` в этом файле **небезопасно**, так как при добавлении или удалении дисков их имена могут измениться (например, `/dev/sdb1` может стать `/dev/sdc1`), что приведет к тому, что система не загрузится или не примонтирует нужный диск.
**UUID решает эту проблему.** Даже если вы поменяете порт подключения диска или добавите новый накопитель, UUID раздела останется неизменным.

#### Как добавить диск в `/etc/fstab` правильно:

1. Узнайте UUID нужного раздела с помощью `blkid`.
    
2. Откройте `/etc/fstab` (например, через `nano /etc/fstab`).
    
3. Добавьте строку, используя UUID вместо имени устройства:
    

```
UUID=a1b2c3d4-e5f6-4a5b-8c9d-0e1f2a3b4c5d  /mnt/data  ext4  defaults  0  2
```
**Разбор строки:**

- `UUID=...`: Уникальный идентификатор, полученный через `blkid`.
    
- `/mnt/data`: Точка монтирования (папка, куда диск будет "прицеплен").
    
- `ext4`: Тип файловой системы (тоже берется из вывода `blkid`).
    
- `defaults`: Опции монтирования по умолчанию.
    
- `0 2`: Параметры для утилиты `dump` и проверки файловой системы `fsck`.
