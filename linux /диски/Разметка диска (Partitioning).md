## Разметка диска (Partitioning)
Это **менеджеры разделов**. Их задача — «разрезать» физический диск на логические части (разделы), чтобы операционная система видела их как отдельные устройства (например, `/dev/sda1`, `/dev/sda2`).

Для создания и управления таблицами разделов:

- **`fdisk`** — классический инструмент для MBR и GPT (интерактивный).
#### 1. Запуск
```
sudo fdisk /dev/sdX
```

_(Замените `sdX` на ваш диск, например `sda` или `sdb`. Не `sda1`!)_

------
### 2. Основы управления (внутри программы)

После запуска вы окажетесь в интерактивной среде. Вот базовые клавиши:

- **`m`** — показать справку (если забыли команды).
    
- **`p`** — **P**rint: показать текущую таблицу разделов (что сейчас на диске). !!!
    
- **`n`** — **N**ew: создать новый раздел. !!!
    
- **`d`** — **D**elete: удалить раздел. !!!
    
- **`t`** — **T**ype: изменить тип раздела (например, под Linux, Swap или EFI).
    
- **`q`** — **Q**uit: выйти без сохранения изменений (безопасный выход).  !!!
    
- **`w`** — **W**rite: записать изменения на диск и выйти (после этого изменения вступят в силу). !!!

----

### 3. Типовой сценарий (Создание раздела)

1. **`p`** — посмотрите, что уже есть.
    
2. **`n`** — нажмите, чтобы создать раздел.
    
    - Вас спросят тип (обычно жмите `Enter` для значения по умолчанию: _Primary_).
        
    - Спросят номер раздела (обычно `Enter` для следующего свободного).
        
    - Спросят первый и последний сектор (обычно `Enter` — использовать всё место от начала до конца).
        
3. **`p`** — проверьте, появился ли новый раздел в списке.
    
4. **`w`** — если всё верно, нажмите `w` для сохранения.

---

### 4. Что делать ПОСЛЕ `fdisk`?

**Когда нужно делать `mkfs`:**
Только если ты создал **абсолютно новый** раздел, на котором еще нет никаких важных файлов, и хочешь подготовить его к первому использованию. (потому что он удалит все данные с раздела)

`fdisk` просто «разрезает» диск, но файловую систему он не создает. После разметки нужно отформатировать новый раздел:



- **Для ext4 (стандарт для Linux):**
    
    Bash
    
    ```
    sudo mkfs.ext4 /dev/sdX1
    ```
    
- **Для FAT32 (для совместимости):**
    
    Bash
    
    ```
    sudo mkfs.vfat -F 32 /dev/sdX1
    ```
    

_(Замените `sdX1` на имя вашего нового раздела, например `sdb1`)_

### что бы не допустить ошибку Запомни порядок при работе в консоли

Если правишь таблицы через CLI (`fdisk` / `parted`):

- **Уменьшаешь раздел:**
    
    1. Сначала сжимаешь ФС с запасом: `sudo resize2fs /dev/sda1 400G`
        
    2. Потом режешь сам раздел в `fdisk`.
        
    3. В конце подогоняешь ФС под точный размер: `sudo resize2fs /dev/sda1`
        
- **Увеличиваешь раздел:**
    
    1. Сначала растишь сам раздел в `fdisk`.
        
    2. Потом растягиваешь ФС: `sudo resize2fs /dev/sda1`

> **Главный совет:** Всегда перепроверяйте имя диска перед запуском. Если ошибиться буквой, можно случайно стереть данные с системного диска.
