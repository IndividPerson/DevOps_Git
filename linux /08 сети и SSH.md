`ip addr` (или `ip a`) - Просмотр интерфейсов
`ip route` (или `ip r`) - Управление маршрутами
`ip neigh` (или `ip n`) - Просмотр соседей (ARP)
`ip link set [dev] up/down` - Состояние линка

`ip addr add (ip_addres) dev ...` - присвоить статический айпи адрес

`hostname` - посмотреть имя компютера
`hostname "имя"` - поменять имя хоста

# SSH !!!
с помощю ssh вы управляете сервером который где то далеко с своего компютера (консолью)
Вы вводите команды на своем компютере и они выполняются на совершенно другом компютере где то в другом месте мира
ssh безопасный потому что шифрует информацию которую вы отправляете

**Архитектура системы**
- **SSH-сервер:** процесс (обычно `sshd`), который работает в фоновом режиме на удаленной машине и ожидает входящих соединений.
- **SSH-клиент:** программа на компьютере администратора, используемая для инициирования подключения к серверу.

**Способы аутентификации**
- **Пароли:** классический метод, требующий ввода пароля при каждом подключении.
- **SSH-ключи:** предпочтительный метод для профессионалов, обеспечивающий более высокую безопасность (сложнее подобрать или взломать брутфорсом).
