### Задача: «Детектор пожирателей памяти»

**Твоя цель:** Написать скрипт, который мониторит потребление оперативной памяти процессами.

**Условия:**

1. Скрипт должен найти все процессы, которые потребляют **больше 10% оперативной памяти** сервера.
    
2. Вместо убийства процесса, скрипт должен:
    
    - Вывести сообщение в консоль: `"Внимание! Процесс [имя] (PID: [pid]) потребляет [процент]% RAM!"`
        
    - **Записать это событие в лог-файл** с текущей датой и временем.
        
3. Используй команду `ps -eo pid,pcpu,pmem,comm` (она покажет PID, % CPU, **% RAM** и имя команды).

### Подсказки для выполнения:

- **Как получить время для лога:** используй команду `date`. Например: `echo "$(date) - Процесс съел много памяти" >> memory_log.txt`.
    
- **Как работать с числами с плавающей точкой:** В Bash очень сложно сравнивать дробные числа (например, `10.5` больше `10`?).
    
    - _Хитрость:_ Используй `awk` для проверки условия внутри цикла.
        
    - Пример: `ps -eo pid,pmem,comm | tail -n +2 | awk '$2 > 10.0 {print $1, $2, $3}'`
        
    - Эта строка сама найдет нужные процессы, где 2-я колонка (`pmem`) больше `10.0`. Тебе останется только обработать этот список.
