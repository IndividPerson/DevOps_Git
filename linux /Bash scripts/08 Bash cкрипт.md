
## Конспект: Основы Bash-скриптов

- **Права доступа:** Чтобы запустить файл как программу, нужно дать ему права на выполнение: `chmod +x script.sh`
    
- **Запуск:** `./script.sh`


`$PATH` — это специальная переменная окружения, которая хранит список папок, где система ищет программы при вводе команды в терминале.

## Переменные

- **Присваивание:** Без пробелов вокруг знака `=` (например, `NAME="Alex"` или `name=ls(можно команды,но вместо "" кривые скобки)).
    
- **Обращение:** Используйте символ `$` (например, `echo $NAME`).
    
- **Кавычки:**
    
    - Двойные `"`: разрешают использование переменных внутри (интерполяция).
        
    - Одинарные `'`: выводят текст «как есть» (литерально).



## Специальные переменные

- `$0` — имя самого скрипта.
    
- `$1`, `$2`... — аргументы, переданные скрипту при запуске.
    
- `$#` — количество переданных аргументов.
    
- `$@` — список всех аргументов.
    
- `$?` — код завершения последней выполненной команды (0 — успех, остальное — ошибка).

**`||`**: Это логическое **ИЛИ** (OR)

- **`shift`** — это «перемотка» списка аргументов. Ты выбрасываешь текущий `$1`, и всё сдвигается на одну позицию влево.
    
- **`case`** — это умный «разветвитель». Он проверяет значение переменной и выбирает, какой блок кода запустить (удобнее, чем куча `if`).

## Операторы сравнения

- **Числа:** `-eq` (равно), `-ne` (не равно), `-gt` (больше), `-lt` (меньше).   (())
    
- **Строки:** `==` (сравнение), `=` - привсваевание  `!=` (не равно), `-z` (строка пуста).   \[\[   ]]  (надо с пробелами)
    
- **Файлы:** `-f` (файл существует), `-d` (директория существует), `-e` (существует любой объект).


## Циклы

### `for`

Итерация по списку элементов:

Bash

```
for i in {1..5}; do
    echo "Номер $i"
done
```
 c диапазоном (1..5)

- **Вывод команд:** Используйте `$(команда)` для сохранения результата выполнения команды в переменную.
    
    - _Пример:_ `CURRENT_DATE=$(date)`
        
- **Отладка:** Запускайте скрипт с флагом `-x`, чтобы видеть, что происходит на каждом этапе: `bash -x script.sh`




## Пример скрипта на запрос чисел и их деление
![[Pasted image 20260713222656.png]]
- **`read`**: Останавливает выполнение скрипта и ждет, пока пользователь введет значение и нажмет Enter.
    
- **`scale=2`**: Указывает `bc`, сколько знаков после запятой нужно вывести.
    
- **`|` (конвейер)**: Передает вывод команды `echo` в команду `bc`.
    
- **`if [ "$num2" -eq 0 ]`**: Всегда проверяйте делитель перед делением, иначе скрипт выдаст ошибку, если пользователь введет 0.
![[Pasted image 20260713232319.png]]

**Совет:** Всегда используйте команду `set -e` в начале скрипта, чтобы он немедленно прекращал работу, если какая-то команда завершилась с ошибкой. Это убережет от множества проблем при выполнении последовательных операций.

Команда `read` обладает мощными флагами для управления вводом:

- **`-p "строка"`** — выводит приглашение (prompt) перед чтением. Позволяет объединить `echo` и `read
- **`-s`** (silent) — скрытый ввод. Полезно для паролей (символы не отображаются на экране).
    
- **`-t секунд`** — задает таймаут. Если пользователь ничего не ввел за указанное время, команда завершается с ошибкой.
    
- **`-a массив`** — записать введенные данные в массив.
    
- **`-r`** — **важная опция!** Запрещает интерпретацию обратной косой черты (`\`) как управляющего символа. Всегда используйте `-r` при чтении путей или файлов.
